# Simon Says Game

A simple Simon Says memory game built with vanilla JavaScript.

## Features
- Color-based memory game
- Level tracking
- Score display on game over
- Flash animations for feedback

## Tech Stack
- HTML5
- CSS3
- Vanilla JavaScript

## How to Play
1. Press any key to start the game
2. Watch the color sequence
3. Repeat the sequence by clicking the buttons
4. Each level adds one more color to remember
5. Game ends when you make a wrong move
